01 / SYSTEMS ENGINEERING FEATURED

InferX

Concurrent AI Inference Scheduler

A C++20 inference scheduler designed to coordinate tasks through priority-based dispatch, dynamic batching and worker threads, with latency and throughput measurement.

C++20 Concurrency Thread Pools Priority Queues Performance
IMPLEMENTATION FLOW 01
Incoming Tasks → Priority Queue → Dynamic Batching → Worker Threads
Explore the engineering decisions +

The problem

Scheduling tasks with different priorities requires balancing responsiveness, coordination and throughput.

Implementation

I implemented a priority-based scheduler with dynamic batching, worker threads, mutexes and condition variables to coordinate task execution.

Performance measurement

The project tracks throughput and p50, p95 and p99 latency to examine how scheduling decisions affect observed performance.

Engineering takeaway

Looking beyond average latency provides a better picture of scheduling behaviour, particularly when some tasks experience longer delays than others.

02 / SYSTEMS ENGINEERING FEATURED

CacheForge

Thread-Safe LRU / TTL Cache

A reusable C++20 cache library and CLI implementing least-recently-used eviction, time-to-live expiration and synchronization for concurrent access.

C++20 Hash Maps Linked Lists CMake GoogleTest
IMPLEMENTATION FLOW 02
Cache API → Hash Map ↔ LRU List + TTL Checks
Explore the engineering decisions +

The problem

A cache must support efficient lookup, predictable eviction and expiration while protecting shared state during concurrent access.

Data structures

I used a hash map and linked list to implement least-recently-used cache behaviour, alongside TTL expiration checks.

Concurrency and testing

Shared operations are synchronized, and GoogleTest is used to validate cache behaviour and edge cases. The implemented tests passed.

Engineering takeaway

Correctness depends on both the data structures and the way concurrent operations interact with eviction and expiration.
