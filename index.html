SOURCE-BASED ENGINEERING EVIDENCE v0.8

How workers consume batches

The worker loop waits for a batch on the thread-safe queue and passes it to the processing function. The queue's shutdown behaviour controls when workers exit.

src/worker_pool.cpp C++20 
void WorkerPool::workerLoop(
    std::size_t workerId
)
{
    Batch batch;

    while (batchQueue_.waitAndPop(batch))
    {
        processBatch(
            workerId,
            batch
        );
    }
}

Explore the engineering decisions +

Scheduling

FIFO and priority scheduling provide alternative ways to order incoming requests.

Concurrency

A worker pool consumes batches from a thread-safe queue, using synchronization to coordinate work.

Metrics

Latency percentiles and throughput help describe execution behaviour beyond average latency alone.

Limitations

Processing time is simulated. Real-model inference and formal comparative benchmarking are outside the current completed milestone.
